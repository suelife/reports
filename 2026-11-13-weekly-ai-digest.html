Claude Code「don't ask again」曾把含密碼的指令寫進設定檔，2.1.323 已修正；email 問題仍未完全修正

▲ 需行動

日期：2026/11/09 至 11/12（11/07 揭露為前期）（台北時間）

2.1.323 以前，選「Yes, and don't ask again」會把含密碼的整條指令寫進 .claude/settings.local.json，帳號 email 也可能進到 User-Agent。Apiiro 在 GitHub 找到 1,122 份公開副本含至少一個密鑰、共 1,379 個（未測是否仍有效）。2.1.323（11/12）起，疑似含密鑰或會寫進受 git 追蹤設定檔的允許規則只在當次 session 有效、不再存檔；email 部分，2.1.321（11/9）只縮小檢查範圍，截至 2.1.323 changelog 仍未見「從 context 移除 email」。已經外洩的密鑰仍要輪替，並用 git rm --cached 移出版控、加進 .gitignore。
