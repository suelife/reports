⚙️ 攻擊鏈技術分析

DLL 側載（DLL Sideloading）

本次行動核心技術：濫用兩個合法簽章的執行檔進行 DLL 側載。

合法執行檔來源惡意 DLL載入惡意程式
fmapp.exe富迪科技（Fortemedia）音訊驅動工具fmapp.dllChromElevator
sentinelmemoryscanner.exeSentinelOne 端點防護元件sentinelagentcore.dllChromElevator
安全工具被武器化 SentinelOne 的二進位檔具有合法數位簽章，許多端點防護會自動信任同業簽章。攻擊者刻意選擇安全軟體元件來繞過安全工具——此模式已被 Storm-0249、Cephalus 勒索軟體等不同組織複製。

ChromElevator 竊資軟體

公開可取得的後滲透工具，能繞過 Google Chrome v127+ 引入的 App-Bound Encryption（ABE） 防護：

  • ABE 機制：Chrome 透過 Windows 特權服務驗證存取 cookie/密碼的程序是否為 Chrome 本體
  • 繞過方式：透過 COM 介面與 Chrome 的 IElevator 服務通訊，在與瀏覽器相同資料夾下執行偽裝
  • 竊取內容：瀏覽器密碼、Cookie、付款資料
  • 相容性：Chrome 143（IElevator）、Chrome 144+（IElevator2）及未來版本

Node.js 自動化編排

本次行動的一大特色：使用 node.exe 作為攻擊編排引擎。PowerShell 偵察指令與 DLL 側載均由 node.exe 觸發，呈現 ~90 秒週期的自動化 beaconing 行為。

意義 攻擊者已從「人工坐在鍵盤前操作」轉向「自動化植入物自主執行」，顯示作戰成熟度的躍升。

⚠️ 衝擊評估

作戰成熟度的躍升

  • 編排自動化：從原始 PowerShell → Node.js 自動化驅動
  • 隱匿性提升：DLL 側載取代直接投放惡意執行檔
  • 工具冗餘：部署多套憑證竊取工具，確保任一被攔截仍可運作
  • 外洩管道偽裝：使用消費級 sendit[.]sh 服務混入正常流量

安全工具被武器化的警示

SentinelOne 的合法元件被用作攻擊跳板，揭示端點安全產業的結構性風險：安全產品的簽章檔案享有較高系統信任，攻擊者刻意利用這層信任。此模式已被 Storm-0249、Cephalus 等不同組織複製，形成跨組織的知識擴散。

地緣政治意涵

  • MuddyWater 從傳統中東/北非目標擴展至東亞（韓國），打破既有認知
  • 針對電子製造商可能意圖竊取工業/智慧財產，或取得供應鏈下游存取權
  • 配合中東機場、政府機關的同期入侵，MOIS 正在全球建構戰略情報收集網

Chrome ABE 防護的持續瓦解

ChromElevator 只是眾多 ABE 繞過工具之一。自 Chrome v127 引入 ABE 以來，Stealc、Vidar、LummaC2、Meduza、VoidStealer 等竊資軟體家族均已實作各自繞過方案，這道防線正在被系統性攻破。

🛡️ 防禦建議

即時行動

  • 偵測 DLL 側載：監控 fmapp.exe 和 sentinelmemoryscanner.exe 從非標準路徑（如 AppData\Local\[隨機]\）執行
  • 阻斷已知 IOC：將上述 IP、Domain、檔案雜湊加入防火牆與 EDR 規則
  • 監控 node.exe 異常行為：node.exe 作為 cmd.exe 或 powershell.exe 的父程序是高度異常的
  • 封鎖公開檔案傳輸服務：sendit[.]sh 等服務不應被企業端點存取

中期強化

  • 應用程式白名單：限制非預期的合法簽章二進位檔執行
  • Registry Run Key 監控：偵測 CurrentVersion\Run 中隨機命名的值
  • SAM 存取告警：監控 reg save hklm\sam 等登錄檔傾倒行為
  • PowerShell ScriptBlock Logging：啟用以捕捉偵察指令
  • 憑證管理：將機敏密碼從瀏覽器遷移至獨立密碼管理器

長期策略

  • 零信任架構：不因二進位檔具有合法簽章就自動信任
  • 供應鏈安全評估：審視環境中所有第三方安全工具的可被濫用元件
  • 威脅情報訂閱：持續追蹤 MuddyWater / Seedworm 的 TTPs 演化
