事件概述 2026 年 5 月 3 日，鴻海威斯康辛州 Mount Pleasant 廠區爆發大規模 IT 系統中斷，涵蓋 Wi-Fi、打卡系統、生產線工作站，導致全廠停工約一週。5 月 11 日，Nitrogen Ransomware 組織在暗網宣稱對此事件負責，聲稱竊取 8TB 資料。鴻海官方僅承認「技術問題」，迄今未確認遭勒索或資料外洩。

感染鏈（四階段）

Stage 1
惡意廣告
Google / Bing 投放假廣告，冒充 WinSCP、AnyDesk、Slack 等 IT 工具
Stage 2
木馬安裝包
使用者下載並執行帶有後門的「官方」安裝程式
Stage 3
DLL Sideloading
惡意 DLL 替換合法系統檔案，繞過防毒偵測
Stage 4
C2 植入
記憶體內載入 Cobalt Strike / Sliver → AD 橫向移動 → 資料外傳 → 加密
🔬 關鍵技術發現
🚨
重要：ESXi 解密器存在致命 Bug，付贖金也無法還原檔案 Coveware 研究人員確認 Nitrogen 的 ESXi 加密模組有記憶體錯誤，導致加密金鑰損毀。即使受害者支付贖金，攻擊者本身也無法解密檔案。

技術細節（Coveware 分析）

// 問題所在：記憶體偏移衝突 rsp+0x1c → 載入 8-byte 變數（QWORD variable） rsp+0x20 → 公鑰（Public Key）存放位置 // 結果：變數覆蓋公鑰前 4 bytes corrupted_key = key_bytes[:4] → 被覆蓋 + key_bytes[4:] // 影響：生成的公鑰沒有對應的私鑰 // 加密後，雙方（攻擊者 + 受害者）均無法解密

此 bug 僅影響 ESXi 版本；Windows 版解密器是否有相同問題尚未確認。

🛡️
新談判反制戰術（2026 年發現） Nitrogen 會封鎖專業談判公司的 IP 位址，使受害者無法透過有經驗的中介降低贖金或爭取時間。應對方式：更換 VPN 出口節點或請 ISP 重新分配動態 IP。

🔍 防禦建議（針對本次 TTPs）
攻擊向量防禦措施
惡意廣告初始存取 部署 DNS 過濾 / 廣告攔截；IT 採購軟體只允許從內部核可的軟體庫下載
DLL Sideloading 應用程式白名單（WDAC / AppLocker）；監控非預期 DLL 載入行為
AD 橫向移動 Defender for Identity（偵測 Pass-the-Hash / Pass-the-Ticket）；網段隔離；最小權限原則
Cobalt Strike C2 監控異常 Beacon 流量；封鎖已知 Nitrogen C2 IP（保加利亞 / 荷蘭 ASN）
OT/IT 同網段 製造業 OT 網路與企業 IT 網路物理/邏輯隔離；打卡機獨立 VLAN
ESXi 特別注意 備份 ESXi VM 於離線媒介；即使支付贖金 ESXi 檔案仍無法還原，勿付贖金
