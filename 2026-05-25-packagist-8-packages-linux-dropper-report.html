📋 Executive Summary

2026 年 5 月 21 日前後，攻擊者在 Packagist 上 8 個 PHP 套件的 package.json 中植入惡意 postinstall 腳本，利用開發者執行 npm install 的時機下載並執行 Linux binary。此手法刻意規避針對 PHP 依賴的安全掃描，利用 PHP 套件混搭 JavaScript 建構工具的常見實務作為盲區。惡意 payload 的 GitHub 源帳號（parikhpreyash4）已在事件曝光後刪除，binary 完整行為尚未完整逆向分析，目前排除了資料外洩的直接證據，但長尾風險仍存在。

🎯 攻擊者背景

攻擊者身份未知，唯一已知線索為 GitHub 帳號 parikhpreyash4，以 systemd-network-helper-aa5c751f 為 repository 名稱（偽裝為系統服務），在事件曝光後立即刪帳號。無法確認其國籍、組織關聯或動機。

與 TeamPCP（Mini Shai-Hulud）的比較：兩者均使用 npm 生態作為攻擊向量，但 TeamPCP 使用 OIDC token 自我繁殖、具備 SLSA Level 3 attestation，技術成熟度遠高於本事件。本事件手法較簡單，可能為獨立機會性攻擊者。

⚙️ 攻擊鏈技術分析

核心手法：跨生態系盲區規避

現代 PHP 套件常搭配前端建構工具（Webpack、Vite、Node.js scripts），因此在 composer.json 之外也包含 package.json。安全掃描工具若僅分析 PHP 依賴管理，會跳過 JavaScript 生命週期 hook，形成盲區。

攻擊流程：

  1. 攻擊者在 8 個套件的 package.json 中插入 postinstall 腳本（非 composer.json）
  2. 開發者執行 npm install 時自動觸發 postinstall
  3. 腳本透過 curl 從 github.com/parikhpreyash4/systemd-network-helper-aa5c751f/releases 下載 Linux binary
  4. Binary 儲存於 /tmp/.sshd（偽裝為 SSH daemon），賦予執行權限，後台靜默執行

受影響套件清單：

  • moritz-sauer-13/silver
  • crosiersource/crosierlib-base
  • devdojo/wave
  • devdojo/genesis
  • katanaui/katana
  • Elitedevsquad/sidecar-laravel
  • r2luna/brain
  • baskarcm/tzi-chat-ui

未解之謎：binary 執行後的具體行為（資料外洩目標、C2 通訊、持久性）因帳號刪除而無法完整分析。

  • 777 個 GitHub 引用：是同一攻擊者佈置的備用 payload，還是其他攻擊者複製使用？目前無法確認
  • 感染時間窗口：套件何時被植入惡意代碼、受感染版本存活多久，目前無精確紀錄
🛡️ 防禦建議

立即

  1. 檢查 /tmp/.sshd 是否存在：ls -la /tmp/.sshd 2>/dev/null && echo "INFECTED"
  2. 確認是否安裝過上述 8 個套件的受影響版本，若有則全面輪換該機器的所有機密（SSH keys、cloud credentials、.env）
  3. 掃描 process list 是否有可疑的 /tmp 路徑執行：ps aux | grep /tmp/

中期

  1. 停用 CI 環境中的 postinstall：使用 npm ci --ignore-scripts 防範 package.json 腳本攻擊
  2. PHP 套件掃描需涵蓋 package.json：告知 SCA 工具需同時分析跨生態系依賴
  3. Composer lockfile commit hash pinning：composer.lock 應鎖定到具體 commit，而非僅版本號
