數發部：十餘家企業受害，外洩規模更新為約 800 萬筆，近半數攻擊事件與 AI 有關

▲ 需行動

日期：2026/11/11 至 11/12（台北時間）

數發部 11/11 說「逾百萬份個資」外洩，11/12 資安署副署長更新為「約 800 萬筆」。部長 11/9 稱較大受駭企業約五、六家；資安署副署長 11/12 提到 91APP、易遊網、永豐銀行等民間企業，並稱約十多家企業受害、高達 800 萬筆個資外洩。攻擊多打 PHP、Node.js、GitLab 已知漏洞與高權限 API，數發部提出個資保護五大行動，前四項都以 72 小時為限（重大警訊修補、通報主管機關、通知當事人、找出原因或修補），第五項是一個月內提出檢討改善計畫並落實個資最小化。這代表台灣企業的修補與通報時程正被明確要求收緊。

微軟 11 月 Patch Tuesday 修補已遭利用的 Outlook 零時差 CVE-2026-124194

▲ 需行動

日期：2026/11/11（台北時間）

開啟特製訊息檔就會外洩 NTLMv2 雜湊，且已遭實際利用。本月修補總數 SecurityWeek 寫 1,094 個、BleepingComputer 寫 1,235 個（算法不同）。CISA 美東 11/10 列入 KEV，聯邦期限 11/24。只要誘使使用者開啟檔案即可觸發（預覽窗格不會觸發），Outlook 用戶基數大，應優先套用本月更新。

Barracuda ESG 兩漏洞串接可免登入取得 root，已遭利用並列 KEV

▲ 需行動

日期：2026/11/10 至 11/11（台北時間）

CVE-2026-116606（CVSS 9.3）與 111560（CVSS 8.6）可串成免登入 root，前提是連得到 Admin UI。Barracuda 台北 11/10 10:00 更新稱少數組織遭利用，CISA 美東 11/10 列入 KEV、聯邦期限 3 天；Previdian 11/9 到 11/11 觀察到 17 次嘗試、15 個 IP。官方公告的 ESG 修補為 BNSF-40425（9.4.017 以上）與 BNSF-40430（9.4.017 以下）；CVE-2026-111560 也影響 ADC、BMA、WCC、WAF、WSG 等其他 Barracuda 產品。套用修補之外，也要確認 Admin UI 沒有對外開放。

來源trust.barracuda.com來源bleepingcomputer.com來源securityweek.com

N-able N-central 零時差 4EverAble2Shell 在 PoC 公開數小時內遭利用，HF2 也擋不住

▲ 需行動

日期：2026/11/12 至 11/13（利用發生於台北 11/12 16:30 到 20:50，報導為台北 11/13 03:51）（台北時間）

huntback 稱至少 21 台遭裝挖礦程式，其中 19 台已是 2026.4.1.26 HF2；利用條件是開啟 Legacy API。另一個 Agent2Shell 可對 Windows 代理以 SYSTEM 執行。N-able 11/13（美國 11/12）公告限制部分功能與整合：託管環境已關閉 Intune 整合，地端版的 Intune 整合由 N-able 暫時停用，並要求地端客戶確認 Legacy API 已關閉；當時稱未見入侵跡象，但台北 11/13 11:50 更新稱已發現更多入侵指標（IOC），正與相關客戶合作處理。N-able 稱後續 hotfix 準備中，截至 11/13 尚無修補（Tenable）。

來源bleepingcomputer.com來源huntback.io來源tenable.com來源uptime.n-able.com來源n-able.com

ScreenConnect 雲端版遭濫用攻擊 MSP，源頭指向第三方擴充 RMM+

▲ 需行動

日期：2026/11/12（台北時間）

攻擊自台北 11/12 01:47 起，90 分鐘內打完；Huntress 最新統計 288 台、48 個組織（初報 6 家 MSP、286 台、47 個組織）。Huntress 研判可能是 RMM+ 1.0.31／1.0.32 的認證弱點：未設金鑰時接受空白金鑰，且因不經 ScreenConnect 帳號機制，可能不必突破 MFA 就能下指令；Huntress 初報時也稱活動看來是濫用合法功能，而非利用軟體漏洞。ConnectWise 尚未證實初始入侵方式，已停用 5 個相關擴充。一個第三方擴充就可能讓 MSP 的客戶一起曝險。

本週趨勢

  1. AI 代理攻擊已成常態：BOSSAI 打台北 119、越獄 DeepSeek 代理打電信商、Fireworks 與 Railway 的 LLMjacking 盜刷，數發部也稱近半數攻擊事件與 AI 有關。共通點是打已知漏洞與沒擋登入的地方，有登入防護的系統多數沒被攻破。
  2. 供應鏈與委外是本週主戰場：CYBERBIZ、netiCRM、91APP、ScreenConnect 的第三方擴充 RMM+、N-able、Xen Orchestra，一家服務商出事就連到一串客戶；數發部已邀集平台型業者加入情資分享，並對已出事的業者進行行政檢查。
  3. 遠端管理工具與郵件閘道持續遭利用，從 PoC 公開到實際攻擊只要數小時。
  4. AI 估值變保守：Anthropic 估值討論下修、Nvidia 換帥，台積電同時入股 Anthropic 與 OpenAI。

本週行動清單（一般性建議）

  1. 套用微軟 11 月更新，優先處理 Outlook CVE-2026-124194。
  2. 使用 Barracuda ESG、SonicWall SSL VPN、N-able N-central、Xen Orchestra 者立即套用最新修補；尚無修補的項目先依官方緩解措施限制權限，並確認管理介面沒有對外開放。
  3. MSP 與使用遠端管理工具的單位，盤點第三方擴充與外掛，停用不必要的項目並確認 MFA 不能被繞過。
  4. Linux 與 SSH 相關修補：確認 CVE-2026-98432 與 OpenSSH CVE-2026-123158 都已更新，SSH 更新後重啟 sshd。
  5. 使用 AI 程式工具者檢查專案設定檔是否誤存密碼或密鑰，確認不在版控內，並輪替曾外露的密鑰。
  6. 曾在 CYBERBIZ、91APP 相關品牌購物或曾捐款給 NGO 者，留意冒名通知與釣魚訊息。
  7. 企業依數發部 72 小時原則檢視自己的修補與外洩通報流程。
